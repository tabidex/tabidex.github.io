# TABIDEX ― 旅の記録カードのページ

旅の記録カード（トレカ）のQRコードから開く、スマホ向けの小さなサイトです。

```
カードのQR → 旅の表紙ページ → 「動画を見る」ボタン → Googleフォトのアルバム
```

- トップページ：<https://tabidex.github.io/>（全部の旅のカード一覧。番号の大きい順＝新しく作ったカードが上に並びます）
- 旅の表紙ページ：`https://tabidex.github.io/trip/001/`（旅の番号ごと）

**旅の追加やリンクの変更は、GitHub のブラウザ画面だけでできます。**
プログラムを書く必要はありません。`trips` フォルダの設定ファイルを1つ作る（または書き換える）だけで、
表紙ページ・トップの一覧・QRコードが自動で作られて公開されます。

## 1. しくみ（ざっくり）

```
あなた：trips/002.yml を作って「Commit changes」（保存）
   ↓ 自動（GitHub Actions）
① 設定ファイルの書き間違いをチェック
② 表紙ページ・トップの一覧・QRコードを作る
③ サイトに公開（1〜3分くらい）
```

- 書き間違いがあると、**②③は行われず、サイトは前回の正しい状態のまま**です。
  すでに印刷したカードのQRが使えなくなることはありません。
- どこが間違っているかは、GitHub の「Actions」画面に日本語で表示されます（[7章](#7-公開できたか確かめるうまくいかないとき)）。

## 2. 最初に1回だけやること

### 2-1. GitHub Pages の公開方法を「GitHub Actions」にする

1. GitHub で `tabidex/tabidex.github.io` のページを開きます。
2. 上のメニューの **Settings**（歯車マーク）を押します。
3. 左のメニューの **Pages** を押します。
4. 「Build and deployment」の **Source** を **GitHub Actions** にします。
   （「Deploy from a branch」になっていたら、押して「GitHub Actions」を選びます。選ぶだけで保存されます。）

### 2-2. Actions が使えるか確かめる

1. **Settings** → 左のメニューの **Actions** → **General** を開きます。
2. 「Actions permissions」が **Disable actions** になっていなければOKです。
   （「Allow all actions and reusable workflows」がいちばん簡単です。）

> 組織（tabidex）の設定で止められている場合は、組織のページの **Settings → Actions → General** でも同じ確認をします。

### 2-3. 最初の公開

最初のプログラム一式は「Pull request（プルリクエスト）」として届きます。

1. 上のメニューの **Pull requests** を押し、届いているものを開きます。
2. 下の方の緑のボタン **Merge pull request** → **Confirm merge** を押します。
3. 上のメニューの **Actions** を押すと、自動で動き始めているのが見えます。
   緑の ✓ になったら公開完了です。<https://tabidex.github.io/trip/001/> を開いて確かめます。

> 2-1 より先にマージして ✗ になった場合：Actions でその行を開き、右上の **Re-run all jobs** を押せばやり直せます。

### 2-4. （おすすめ）メールアドレスを公開しない設定

ブラウザから保存（コミット）すると、記録に名前とメールアドレスが残ります。
公開リポジトリなので、本物のアドレスではなく GitHub の「noreply アドレス」が使われるようにしておきます。

1. 右上の自分のアイコン → **Settings** → 左の **Emails** を開きます。
2. **Keep my email addresses private** にチェックを入れます。
3. **Block command line pushes that expose my email** にもチェックを入れます。

## 3. 新しい旅を追加する

例として、No.002 を追加します。

### 3-1. お手本の中身をコピーする

1. リポジトリのトップで **trips** フォルダを開きます。
2. **`_見本.yml`** を開きます（説明つきの白紙見本です。`001.yml` を使ってもOKです）。
3. ファイルの中身の右上にある **コピーのマーク（四角が2つ重なったマーク・「Copy raw file」）** を押します。
   これで中身がまるごとコピーされます。

### 3-2. 新しいファイルを作る

1. **trips** フォルダの画面に戻ります。
2. 右上の **Add file** → **Create new file** を押します。
3. 上の「Name your file...」に **`002.yml`** と入力します。
   - 半角数字3けた ＋ `.yml` です（`2.yml` や `002.yaml` は ✗）。
   - 画面上の場所が `tabidex.github.io / trips / 002.yml` になっていることを確かめます。
4. 下の大きな入力欄に、さきほどコピーした中身を貼り付けます。

### 3-3. 中身を書き換える

`#` から右側は説明のメモです（そのまま残しておいてOK）。書き換えるのは「`:` の右側」だけです。

```yaml
number: "002"               ← ファイル名と同じ番号
place_en: Okinawa           ← 英語の地名（半角英字）
place_ja: 沖縄               ← 日本語の地名
start: 2026-01-01           ← 始まりの日（年-月-日）
end: 2026-01-03             ← 終わりの日
color: "#3A7BD5"            ← テーマカラー（" " で囲む！）
message: |                  ← 一言（下の行から、行頭に半角スペース2つ）
  ここに一言を書きます
  2行目も書けます
album_url: ""               ← アルバムのURL（まだ無ければ "" のまま）
qr_icon: "plane"            ← QRの真ん中の乗り物（plane / car / train / ship、なしなら ""）
```

**テーマカラーの選び方**：「カラーコード 選ぶ」などで検索すると、色を選んで `#3A7BD5` のようなコードを調べられるサイトがあります。
明るい色（黄色・水色など）を選ぶと、文字は自動で濃い色になります。

### 3-4. 保存する

1. 右上の緑のボタン **Commit changes...** を押します。
2. 出てきた画面で **Commit directly to the `main` branch** が選ばれていることを確かめます。
3. もう一度 **Commit changes** を押します。

これで自動の作業が始まります。[7章](#7-公開できたか確かめるうまくいかないとき)の方法で、公開できたか確かめてください。

## 4. 一言やアルバムのURLを変える

1. **trips** フォルダで、変えたい旅のファイル（例：`001.yml`）を開きます。
2. 右上の **鉛筆のマーク（Edit this file）** を押します。
3. 中身を書き換えます。
4. **Commit changes...** → **Commit changes** で保存します。

アルバムのURLは何度変えても大丈夫です。QRコードが指しているのは表紙ページなので、
**印刷したカードはそのまま使えます**。

## 5. GoogleフォトのアルバムのURLを調べる

アルバムは「リンク共有はオフ・招待した家族だけが見られる」設定で使います。
そのため、`album_url` には **共有リンクではなく、アルバムを開いたときのアドレスバーのURL** を入れます。

1. パソコンのブラウザ（Chrome・Safari など）で <https://photos.google.com/> を開きます。
2. 左の **アルバム** から、その旅のアルバムを開きます。
3. 画面のいちばん上の **アドレスバー** のURLをコピーします。
   `https://photos.google.com/album/〜` のような形です（`https://photos.google.com/share/〜` の形でもOK）。
4. 設定ファイルの `album_url: ""` の `""` の中に貼り付けます。

```yaml
album_url: "https://photos.google.com/album/AF1Qip〜〜〜"
```

> ⚠️ **スマホのGoogleフォトアプリの「共有」→「リンクを作成」は使わないでください。**
> リンクを知っている人なら誰でも見られる設定になってしまいます。
>
> ・家族は、アルバムに招待されたGoogleアカウントでログインしていると見られます。
> ・URLに `/u/1/` のような部分が入っていても大丈夫です（自動で外します）。
> ・写真を1枚開いた状態のURL（`/photo/` が入っているもの）は使えません。アルバムの一覧の画面に戻ってからコピーしてください。

## 6. QRコードを取り出して印刷する

公開が終わると、旅ごとにQRコードの画像ができています。ブラウザで開いて保存します。

| 用途 | URL（No.001 の例） |
|---|---|
| 高解像度PNG（2048×2048） | <https://tabidex.github.io/trip/001/qr.png> |
| SVG（拡大してもきれい・印刷所向け） | <https://tabidex.github.io/trip/001/qr.svg> |

`001` の部分を旅の番号に変えて開き、画像を長押し（パソコンは右クリック）→「画像を保存」で保存します。
Actions の結果画面（[7章](#7-公開できたか確かめるうまくいかないとき)）にも、各QRへのリンクが表示されます。

- QRコードの中身は「その旅の表紙ページのURL」です。
- 色は旅のテーマカラー、背景は白、点は丸、四隅は角丸です。
- テーマカラーが明るめ・中くらいの明るさの場合は、読み取りやすくするために **QRの色だけ** 自動で少し濃くなります（ページの色はそのままです）。
- 作るたびに、プログラムで実際に読み取れるかを確かめています。
- **印刷したら、必ずスマホで読み取れるか試してください。** 小さすぎると読み取れないことがあります（目安：1辺 2cm 以上）。

## 7. 公開できたか確かめる・うまくいかないとき

### 結果の見かた

1. リポジトリの上のメニューの **Actions** を押します。
2. いちばん上の行が、さっき保存した分です。
   - 🟡 黄色の丸：作業中（1〜3分待ちます）
   - ✅ 緑の ✓：公開完了！ サイトを開いて確かめましょう
   - ❌ 赤の ✗：書き間違いがあります。**サイトは前回のまま**です
3. 赤の ✗ のときは、その行を押します。下の方の **Summary（まとめ）** に、
   「どのファイルの・何行目を・どう直すか」が日本語の表で出ています。
4. [4章](#4-一言やアルバムのurlを変える)の手順でファイルを直して保存すると、もう一度自動でチェックされます。

> GitHub から「Run failed」というメールが届くこともあります。中身は同じです。
> 公開されたあと、スマホで古いページが見えるときは、少し待つか、ページを再読み込みしてください。

### よくある間違い

| 表示されるメッセージ（の一部） | 直し方 |
|---|---|
| 「"」で囲んでください | `color: #3A7BD5` → `color: "#3A7BD5"` |
| 「：」が全角になっています | `place_ja：沖縄` → `place_ja: 沖縄`（半角の `:` と半角スペース） |
| 半角スペースを1つ入れてください | `place_en:Okinawa` → `place_en: Okinawa` |
| 一言の文章の行は、先頭に半角スペースを2つ | `message: \|` の下の行の先頭に、半角スペースを2つ入れる |
| 番号とファイル名が合っていません | `002.yml` なら `number: "002"` にする |
| ファイル名は「3けたの半角数字.yml」に | ファイル名を `002.yml` のようにする（ファイルを開いて鉛筆マーク → 上の名前欄で変更できます） |
| 知らない項目があります | 項目名のつづり（`album_url` など）を見本と見比べる |
| 「○○」というアイコンはありません | `qr_icon` を `plane` / `car` / `train` / `ship` のどれか（または `""`）にする |
| カレンダーにない日付 / 年-月-日の形で | `2026-01-03` のように半角で書く |
| 3行までにしてください | 一言を3行以内にする |
| GoogleフォトのURLではないようです | [5章](#5-googleフォトのアルバムのurlを調べる)の方法でURLをコピーし直す |
| ファイルの書き方（YAML）が読み取れません | その行と少し前の行で、`:` の後ろの半角スペース、行頭のスペースのずれ、`"` の閉じ忘れを確認する |

どうしても直らないときは、見本（`_見本.yml`）の中身をもう一度まるごと貼り付けて、書き直すのが早道です。

### 「△ 確認してください」が出たとき

黄色の △ は **注意だけ** で、公開はされます。
（例：「地名が長いので文字が小さくなります」「QRの色を少し濃くしました」など）

## 8. 設定ファイルの項目一覧

| 項目 | 内容 | 必要？ | 書き方の例 |
|---|---|---|---|
| `number` | 旅の番号（001〜999）。ファイル名と同じ。URLになる | 必須 | `number: "001"` |
| `place_en` | 英語の地名（半角英字）。表紙でいちばん大きく表示 | 必須 | `place_en: Ishigaki` |
| `place_ja` | 日本語の地名 | 必須 | `place_ja: 石垣島` |
| `start` | 旅の始まりの日 | 必須 | `start: 2025-09-25` |
| `end` | 旅の終わりの日（日帰りなら start と同じ） | 必須 | `end: 2025-09-28` |
| `color` | テーマカラー。`"` で囲む | 必須 | `color: "#3A7BD5"` |
| `message` | 一言（1〜3行）。空なら表示しない | 空でもOK | 下を見てください |
| `album_url` | GoogleフォトのアルバムのアドレスバーのURL。空ならボタンが「準備中」 | 空でもOK | `album_url: "https://photos.google.com/album/〜"` |
| `qr_icon` | QRの真ん中のアイコン。`plane`（飛行機）/ `car`（車）/ `train`（電車）/ `ship`（船）。空ならアイコンなし | 空でもOK | `qr_icon: "train"` |

**一言の書き方**

```yaml
# 1行だけなら
message: 青い海と星空

# 2〜3行なら（「|」の次の行から、行頭に半角スペース2つ）
message: |
  青い海と星空
  また行きたい！

# 書かないなら
message: ""
```

トップページの一覧は、**番号の大きい順**（003 → 002 → 001）に自動で並びます。
新しく作ったカードがいちばん上に来て、一覧の順番はいつもカードの番号と同じです。

期間の表示は自動で整います。

| start / end | 表示 |
|---|---|
| 2025-09-25 / 2025-09-28 | 2025.09.25 - 09.28 |
| 2025-12-30 / 2026-01-02 | 2025.12.30 - 2026.01.02 |
| 2026-04-05 / 2026-04-05 | 2026.04.05 |

## 9. やってはいけないこと・気をつけること

- **カードを印刷したあとに、番号（ファイル名・`number`）を変えない。ファイルを消さない。**
  QRコードの行き先が「ページが見つかりません」になってしまいます。
- **写真・人の名前・泊まった場所（宿名・住所）を書かない。**
  このサイトは誰でも見られます（検索エンジンには出ない設定にしてあります）。
- アルバムは「リンク共有オフ・招待した家族だけ」の設定のまま使う。
- `trips` フォルダで、名前が `_`（アンダーバー）で始まるファイルは公開されません（見本用）。
- `src` フォルダと `.github` フォルダは、自動で動くためのプログラムです。ふだんは触らなくて大丈夫です。

## 10. QRコードの真ん中のアイコン（乗り物）を選ぶ

旅の移動に使った乗り物を、設定ファイルの `qr_icon` で選べます。

| 書き方 | アイコン |
|---|---|
| `qr_icon: "plane"`（または `"飛行機"`） | ✈️ 飛行機 |
| `qr_icon: "car"`（または `"車"`） | 🚗 車 |
| `qr_icon: "train"`（または `"電車"`） | 🚃 電車 |
| `qr_icon: "ship"`（または `"船"`） | 🚢 船 |
| `qr_icon: ""` | アイコンなし |

（表の絵文字はイメージです。実際のアイコンはシンプルな形で、旅のテーマカラーで描かれます。）

**すでに印刷したカードの旅で `qr_icon` を変えると、QRコードの見た目も変わります。**
QRの行き先は同じなので、古いカードもそのまま読み取れます。

### 自分でアイコンを追加したいとき

1. アイコンの画像（**SVG** がおすすめ。PNG も可）を用意します。
   - シンプルな形（線や塗りがはっきりしたもの）がよいです。
   - SVG の中で色を `currentColor` にしておくと、旅のテーマカラーで表示されます。
   - SVG には `viewBox` が必要です（ほとんどのSVGには入っています）。
2. リポジトリで **assets** → **icons** フォルダを開きます。
3. **Add file** → **Upload files** で画像をアップロードし、**Commit changes** を押します。
   ファイル名は半角英数字にします（例：`bus.svg`）。
4. 旅の設定ファイルの `qr_icon` を、拡張子なしの名前にします（例：`qr_icon: "bus"`）。

QRコードは、読み取りの誤りに強い設定（誤り訂正レベルH）で作っています。
アイコンのせいで読み取れなくなった場合は自動で ✗ になり、公開されません。
そのときはアイコンを外す（`qr_icon: ""`）か、別のアイコンにしてください。

## 11. フォルダの中身

```
tabidex.github.io/
├─ trips/                     ← ★ふだん触るのはここだけ
│  ├─ 001.yml                   旅1つ＝ファイル1つ
│  └─ _見本.yml                 新しい旅を作るときのお手本（公開されない）
├─ assets/icons/              ← QRの真ん中のアイコン
│  ├─ plane.svg                 飛行機（qr_icon: plane）
│  ├─ car.svg                   車（qr_icon: car）
│  ├─ train.svg                 電車（qr_icon: train）
│  └─ ship.svg                  船（qr_icon: ship）
├─ src/                       ← 自動で動くプログラム（触らなくてOK）
│  ├─ build.mjs                 全体の流れ
│  ├─ validate.mjs              書き間違いのチェック
│  ├─ color.mjs                 文字色・QRの色を決める
│  ├─ qr.mjs                    QRコードを作る
│  ├─ report.mjs                結果を日本語で表示する
│  ├─ test.mjs                  プログラムの自動テスト
│  ├─ config.mjs                サイトのURLなど
│  └─ templates/                ページのひな形とデザイン（CSS）
├─ .github/workflows/deploy.yml ← 保存するたびに自動で動く設定
└─ package.json など           ← プログラムに必要な部品の一覧
```

<details>
<summary>パソコンで動かしたい人向け（ふだんは不要）</summary>

Node.js 20 以上が必要です。

```bash
npm ci          # 部品のインストール
npm test        # 自動テスト
npm run build   # _site/ フォルダにサイトができる
```

検索エンジン対策として、すべてのページに `noindex` を入れています。
`robots.txt` でクロールを止めると `noindex` が読まれなくなるため、あえて置いていません。

</details>
